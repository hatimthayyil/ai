# upgrade/v1.rs

Format 1 → 2. Owns the frozen format-1 decoders: a message header of nine positional fields with `-` for empty, a node line `ts origin agent model session text` (`splitn(6)`), segments without a column row.

- `to_v2`: every message re-encoded at the same `log/` path, every segment re-encoded under `COLUMNS`. Ids are positions, so they carry over; message texts and node texts are copied byte for byte. `-` becomes empty (format 1 wrote `-` for empty and could not tell it from a literal `-`). A line the old decoder rejects was unbuilt to every reader, so it becomes an empty line.
- Levels are probed `0..64`: level dirs are decimal names, and `walk` reads only the hex fan-out under them.
- Encodes through the live `Message::encode`/`Node::encode`, which write format 2. At the next bump, the format-2 codec moves into `v2.rs` with the 2 → 3 step, and this step encodes through it.
